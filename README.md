# ☁️ Weather Forecast App

The **Weather Forecast App** provides real-time weather updates using the **OpenWeatherMap API**.  
It features a **dynamic UI** that changes with the weather (sunny, cloudy, rainy, etc.).

---

## ✨ Features
- 🌍 Real-time weather updates  
- 🔍 Search by city name  
- 🌡️ Display temperature, humidity, wind speed  
- 🎨 Dynamic themes (sunny, rainy, cloudy, etc.)  
- 📱 Responsive design  

---

## 🛠️ Tech Stack
- **Frontend**: React, CSS/Tailwind  
- **API**: OpenWeatherMap API  
- **State Management**: React Hooks
